# Gize-Studio
Seramik Stüdyomuz için oluşturacağım web uygulaması.

## 🎯 Proje Özellikleri

### 📅 Atölye & Ders Rezervasyonu
- [ ] İnteraktif etkinlik takvimi ve kontenjan takibi
- [ ] Tek seferlik workshop & dönemsel kurs kayıt altyapısı
- [ ] İptal/Değişiklik talepleri ve otomatik e-posta/SMS hatırlatmaları

### 🛍️ E-Ticaret & Hizmetler
- [ ] El yapımı seramik ürün satışı (Sepet & İyzipay/Stripe ödeme entegrasyonu)
- [ ] Açık Atölye (Open Studio) saatlik/aylık üyelik satışı
- [ ] Dışarıdan pişirim alımları için fırın kiralama/raf alanı talep formu

### 🔍 Müşteri Deneyimi & Takip
- [ ] **Ürün Durum Sorgulama:** Kursiyerlerin fırından çıkacak ürün durumunu takip etmesi
- [ ] Sıkça Sorulan Sorular (SSS) ve Atölye Kuralları rehberi
- [ ] Dinamik Instagram feed entegrasyonu
- [ ] Google Maps & İletişim formu
